Windows/PowerShell workflow: `npm run dev` starts local dev server, `npm run build` runs production build and postbuild sync-next-server-chunks step, `npm run lint` runs ESLint/Next lint. TypeScript scripts in scripts/ must be run with `node --no-warnings=MODULE_TYPELESS_PACKAGE_JSON --env-file=.env.local --experimental-strip-types scripts/<name>.ts` per AGENTS.md. Useful shell commands on Windows: `Get-ChildItem`, `Get-Content`, `rg`, `git status`, `git diff`.
