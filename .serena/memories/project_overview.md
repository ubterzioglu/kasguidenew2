Kaş Guide is a Next.js 15 App Router TypeScript city-guide app for Kaş/Antalya. Frontend uses React 19 and a large centralized globals.css; backend/data flows use Supabase admin client on the server. Public content includes places, FAQ, planner, hero slides, and updates/news. Admin area lives under src/app/admin with password-protected CRUD patterns and JSON API routes under src/app/api/admin.
