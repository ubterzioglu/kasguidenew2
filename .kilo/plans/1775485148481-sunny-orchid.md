# Promo Cards Height & Image Resize Plan

## User Objective (Turkish)
- Son promo kartının yüksekliğini yarıya düşür
- Diğerlerini de son promo kartının son yüksekliğine düşür
- Hepsi aynı yükseklikte olsun
- Sağdaki görsellerin genişliğini yüksekliğe eşitle (square images)

## English Translation
- Reduce the last promo card's height to half
- Reduce all other cards to match the new height of the last card
- Make all cards equal height
- Make images on the right square (width = height) proportional to card height

---

## Current State Analysis

### Desktop (≥900px)
- **All 4 promo cards**: 300px height
- **Card grid layout**: 2 columns (content | image)
- **Images (.home-promo-media-wrap)**: 300px × 300px (square)
- **Image aspect**: Already square ✓

### Tablet (≤900px)
- **All cards**: Stacked vertically (1 column)
- **Images**: 100% width × 220px height

### Mobile (≤640px)
- **All cards**: Stacked vertically
- **Images**: 100% width × 200px height

---

## Design Decision: Target Height
**Current last card**: 300px  
**Half of 300px**: 150px  
**New unified height for all cards**: 150px

## Responsive Strategy

| Breakpoint | Old Height | New Height | Image Size | Notes |
|-----------|-----------|-----------|-----------|-------|
| Desktop (≥901px) | 300px | 150px | 150×150px | Cut exactly in half |
| Tablet (≤900px) | 220px (1col) | ~165px | 165×165px | Proportional reduction |
| Mobile (≤640px) | 200px (1col) | ~150px | 150×150px | Match desktop for consistency |
