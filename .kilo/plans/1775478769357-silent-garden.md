# Plan: Gereksiz Dosyaları ve Docs Dosyalarını Temp'e Taşıma

## Hedef
Kök dizindeki gereksiz dosyaları ve `docs/` altındaki tüm dosyaları `temp/` dizinine taşımak.

- `test-limit.mjs`
- `test-limit2.mjs`
- `test-server.js`

### 2. SQL Dosyaları

### 3. MD Dosyaları (Kök Dizin)

### 4. Build/Cache Dosyaları

- `.next-backup-20260329154137/` (eski yedek dizin)

## Uygulama Adımları

1. `temp/` dizini oluştur
2. Test dosyalarını `temp/test/` altına taşı
3. SQL dosyalarını `temp/sql/` altına taşı
4. MD dosyalarını `temp/md/` altına taşı
5. Build dosyalarını `temp/build/` altına taşı
6. `docs/` içeriğini `temp/docs/` altına taşı
7. `old/` dizinini `temp/old/` olarak taşı
8. `upup.png` dosyasını `temp/` altına taşı
9. Boş kalan `docs/` dizinini sil

## Komutlar

```bash
mkdir -p temp/{test,sql,md,build,docs,old}
mv test-*.mjs test-*.js temp/test/
mv *.sql temp/sql/
mv logicplanner.md openlocation.md temp/md/
mv tsconfig.tsbuildinfo temp/build/
mv .next-backup-* temp/build/
mv docs/* temp/docs/
mv old/* temp/old/
mv upup.png temp/
rmdir docs
```
