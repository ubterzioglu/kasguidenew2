### TODO-1.2 · Hero CTA Butonlarına Glasmorphism Efekti Ver

**Dosya:** `src/features/home/components/hero-carousel.tsx`

**Sorun:** Butonlar plain stil, premium hissi yok.

**Çözüm:** Glasmorphism (blur + yarı saydam beyaz/açık yeşil gradient)

**Değişiklikler:**
```css

  background: rgba(255, 255, 255, 0.15);
  backdrop-filter: blur(12px);

  border: 1px solid rgba(255, 255, 255, 0.3);
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.1);
  color: #fff;
  padding: 12px 24px;
  border-radius: 12px;
  font-weight: 600;
  transition: all 0.3s ease;

.hero-primary-action:hover {
  background: rgba(144, 238, 144, 0.25); /* Açık yeşil ton */

  transform: translateY(-2px);
  box-shadow: 0 12px 40px rgba(144, 238, 144, 0.3);
}
```

### TODO-1.3 · Hero Carousel Oklarını Düzelt

**Dosya:** `src/features/home/components/hero-carousel.tsx`

**Sorun:** Ok butonları tıklanınca sahne değişmiyor.

**Kontrol Edilecekler:**
1. `onClick` handler'ları doğru mu?
2. `activeScene` state'i güncelleniyor mu?
3. Console'da JavaScript hatası var mı?

**Değişiklikler:**
```typescript
// Satır 168-178 civarı
<button
  type="button"
  className="hero-carousel-arrow"
  onClick={() => setActiveScene((current) => (current - 1 + heroSlides.length) % heroSlides.length)}
  aria-label="Önceki sahne"
>
  ‹
</button>
<button
  type="button"
  className="hero-carousel-arrow"
  onClick={() => setActiveScene((current) => (current + 1) % heroSlides.length)}
  aria-label="Sonraki sahne"
>
  ›
</button>
```

Eğer `heroSlides` boşsa veya `activeScene` state'i tanımlı değilse düzeltme gerekli.
