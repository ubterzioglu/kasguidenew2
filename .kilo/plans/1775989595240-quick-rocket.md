# Plan: Kullanıcı Mekan Öneri Sistemi

## Özet
Kullanıcıların anonim olarak mekan önerebileceği, admin onaylı bir sistem. `/mekan-oner` sayfasında form, `POST /api/places/submit` endpoint'i, ve mevcut admin panelinde onay akışı.

## Mimari Kararlar
- **Anonim gönderim** — kimlik doğrulama yok, reCAPTCHA/benzeri rate limiting opsiyonel
- **Minimum zorunlu alanlar**: Ad + Kategori + Adres
- **Opsiyonel alanlar**: Telefon, website, açıklama, koordinat (harita)
- **Ayrı sayfa**: `/mekan-oner` route'u
- **Teşekkür mesajı**: Ekranda basit başarı bildirimi
- **Mevcut status akışını kullan**: `pending` → admin panelde `review` → `published`

## Adım 1: Supabase Migration — `intake_channel` genişletme

**Dosya:** `supabase/migrations/YYYYMMDDHHMMSS_add_user_submission_intake_channel.sql`

```sql
alter table places
  drop constraint if exists places_intake_channel_check;

alter table places
  add constraint places_intake_channel_check
  check (intake_channel in ('sweep', 'manual', 'import', 'migrated', 'user_submission'));
```

`PlaceIntakeChannel` tipini de güncelle (`src/types/review.ts`):
```ts
export type PlaceIntakeChannel = 'sweep' | 'manual' | 'import' | 'migrated' | 'user_submission'
```

## Adım 2: API Schema — Zod validation

**Dosya:** `src/lib/api-schemas.ts` — ekle:

```ts
export const UserPlaceSubmissionSchema = z.object({
  name: z.string().trim().min(2, 'Mekan adı en az 2 karakter olmalı').max(200),
  categoryIds: z.array(z.string().min(1)).min(1, 'En az bir kategori seçin').max(3),
  address: z.string().trim().min(5, 'Adres en az 5 karakter olmalı').max(500),
  phone: z.string().trim().max(50).optional(),
  website: z.string().trim().max(500).optional(),
  shortDescription: z.string().trim().max(500).optional(),
  lat: z.coerce.number().min(-90).max(90).optional(),
  lng: z.coerce.number().min(-180).max(180).optional(),
})
```

## Adım 3: Server Action / API Endpoint

**Dosya:** `src/app/api/places/submit/route.ts` (yeni)

- `POST` handler, **yetkilendirme gerektirmez** (herkese açık)
- Zod ile validasyon (`UserPlaceSubmissionSchema`)
- `getSupabaseAdminClient()` ile `places` tablosuna INSERT
- Yeni kayıt: `status = 'pending'`, `verification_status = 'pending'`, `intake_channel = 'user_submission'`
- Slug: `slugifyText(name)` + benzersizlik kontrolü
- `raw_snapshot` alanında `submitted_at` ve `source = 'user_submission'` sakla
- Başarılı response: `{ success: true, data: { id, slug } }`
- Rate limiting: IP bazlı basit throttling (opsiyonel, ileride eklenebilir)

## Adım 4: Frontend — Mekan Öneri Sayfası

**Dosya:** `src/app/mekan-oner/page.tsx` (yeni)

Client component olarak:
- Hero bölümü: "Mekan Öner" başlığı
- Form alanları:
  - **Zorunlu**: Mekan adı (text), Kategori (multi-select dropdown, `CATEGORIES`'den), Adres (text)
  - **Opsiyonel**: Telefon, Website, Kısa açıklama
- Form gönderimi: `fetch('/api/places/submit', { method: 'POST', body })`
- Başarı sonrası: Teşekkür mesajı + "Başka mekan öner" butonu
- Hata durumu: Alan bazlı validation mesajları
- Stil: Mevcut site tasarımına uygun (Tailwind, globals.css class'ları)

**Dosya:** `src/app/mekan-oner/page.tsx` yanında gerekirse `submit-place-form.tsx` client component
